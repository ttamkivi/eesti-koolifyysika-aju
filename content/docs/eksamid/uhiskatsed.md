# Ühiskatsed gümnaasiumisse

## Mis on ühiskatsed?

Ühiskatsed on ühine sisseastumiskatse mitmesse Tallinna prestiižsesse gümnaasiumi korraga. Ühe katsega saab kandideerida mitmesse kooli, mis lihtsustab vastuvõtuprotsessi.

**Osalemine koolid (2026):**
- Tallinna Reaalkool
- Gustav Adolfi Gümnaasium (GAG)
- Tallinna Inglise Kolledž (TIC)
- Tallinna 21. Kool

**Toimumisaeg:** 16. mai 2026

Katsed hõlmavad tavaliselt matemaatikat, eesti keelt ja loodusteadusi (füüsikat). Füüsikakatse on eraldi test, milles hinnatakse teadmisi põhikooli füüsikakursuse ulatuses.

## Katsel antavad valemid

Katse ajal on lubatud kasutada järgmisi valemeid:

**Mehaanika:**
$$F = mg \qquad p = \frac{F}{S} \qquad p = \rho g h \qquad F_\ddot{u} = \rho g V \qquad \rho = \frac{m}{V}$$

**Töö ja võimsus:**
$$A = Fs \qquad N = \frac{A}{t}$$

**Elektriõpetus:**
$$I = \frac{U}{R} \qquad R = R_1 + R_2 \qquad \frac{1}{R} = \frac{1}{R_1} + \frac{1}{R_2} \qquad A = UIt \qquad R = \frac{\rho l}{S}$$

**Soojusõpetus:**
$$Q = cm(t_2 - t_1) \qquad Q = Lm \qquad Q = \lambda m$$

**Valgusõpetus:**
$$D = \frac{1}{f}$$

> ⚠️ Muud valemid (nt kinemaatika valemid $v = \frac{s}{t}$, Ohmi seadus tekstikujul jne) pead ise teadma!

## Teemad katses

Katse hõlmab põhikooli füüsika nelja põhiteema:

1. 🔦 **Valgusõpetus** — valguse levimine, peegeldus, murdumine, läätsed, optiline tugevus
2. ⚙️ **Mehaanika** — jõud, rõhk, tihedus, ujuvus, töö, võimsus, energia
3. 🌡️ **Soojusõpetus** — soojushulk, erisoojusmahtuvus, sulamine, aurumine, kondensatsioon
4. ⚡ **Elektriõpetus** — vool, pinge, takistus, järjestik- ja rööpühendus, töö, võimsus

*Mida mõõdab ampermeeter ja voltmeeter? Kuidas neid ahelasse ühendatakse?*

<details>
<summary>Lahendus</summary>

**Vastus:**

**Mälu reegel:** Voltmeeter = paralleelne (V on rööbiti); Ampermeeter = järjestikku (A on ahelas).

#### Ülesanne F5
*Selgita Archimedese seadust. Millal keha ujub, millal vajub?*

<details>
<summary>Lahendus</summary>

| Keha **vajub** (põhja) | $\rho_{keha} > \rho_{vedelik}$ |

**Hindamisskeem:**

#### Ülesanne A1
*Metallplokk massiga $m = 2{,}5\ \text{kg}$ asub laual. Ploki põhja mõõtmed on $10\ \text{cm} \times 5\ \text{cm}$. Leia ploki avaldatav rõhk lauale.*

<details>
<summary>Lahendus</summary>

**Antud:**
- $m = 2{,}5\ \text{kg}$
- $a = 10\ \text{cm} = 0{,}1\ \text{m}$
- $b = 5\ \text{cm} = 0{,}05\ \text{m}$
- $g = 10\ \text{m/s}^2$

**Otsitav:** rõhk $p$

**Lahendus:**

**Samm 1:** Leia raskusjõud:
$$F = mg = 2{,}5 \times 10 = 25\ \text{N}$$

**Samm 2:** Leia pindala:
$$S = a \times b = 0{,}1 \times 0{,}05 = 0{,}005\ \text{m}^2$$

**Samm 3:** Leia rõhk:
$$p = \frac{F}{S} = \frac{25}{0{,}005} = 5000\ \text{Pa}$$

**Vastus:** Ploki avaldatav rõhk lauale on $p = 5000\ \text{Pa} = 5\ \text{kPa}$.

**Hindamisskeem:**

| Samm | Punktid |
|------|---------|
| Ühikute teisendamine meetriteks | 1p |
| $F = mg$ õige rakendamine | 1p |
| Pindala arvutus | 1p |
| $p = F/S$ rakendamine | 1p |
| Õige vastus ühikuga | 1p |

</details>

#### Ülesanne P3
*Elektrijuhe soojeneb kasutamisel. Selgita seda nähtust. Kuidas mõjutab juhtme paksus soojenemist?*

<details>
<summary>Lahendus</summary>

**Seletus:**

Elektrivoolu mõjul soojenemine on **Joule'i-Lenzi efekt**. Elektrilaengud (elektronid) liikudes põrkuvad juhtme aatomitest — see põrkumine muundab elektrienergia soojusenergiaks:

$$A = UIt = I^2 R t$$

**Juhtme paksuse mõju:**

Takistuse valemist: $R = \frac{\rho l}{S}$

kus $S$ on juhtme ristlõikepindala. Paksem juhe → suurem $S$ → väiksem takistus $R$ → vähem soojust sama voolutugevuse korral.

**Järeldus:** Paksem juhe soojeneb vähem. Seetõttu kasutatakse suure voolu korral paksemaid juhtmeid (turvalisus!).

**Hindamisskeem:**

| Kriteerium | Punktid |
|-----------|---------|
| Soojuse tekke seletus (elektronide põrkumine) | 2p |
| Valem $A = I^2Rt$ või $Q = I^2Rt$ | 1p |
| Takistuse valem $R = \rho l/S$ | 1p |
| Järeldus paksema juhtme kohta | 1p |

</details>

#### Ülesanne P4
*Suvel on asfaltkate kuumem kui muruala. Selgita seda soojusõpetuse seisukohalt.*

<details>
<summary>Lahendus</summary>

**Analüüs:**

Mitu põhjust:

1. **Erisoojusmahtuvus:** Asfaldil on väiksem erisoojusmahtuvus $c$ kui vett sisaldaval murul. Sama soojushulga $Q$ korral: $\Delta t = \frac{Q}{cm}$ — väiksem $c$ tähendab suuremat temperatuuritõusu.

2. **Värvus ja neeldumiskoefitsient:** Must asfaltkate neelab rohkem päikesekiirgust (lähedal ideaalsele mustale kehale), roheline muru peegeldab rohkem.

3. **Aurumisjahtus:** Murus olev niiskus aurub, mis nõuab soojust ($Q = Lm$) — see jahutab muru pinda. Asfaltkate on kuiv, aurumine puudub.

**Hindamisskeem:**

| Kriteerium | Punktid |
|-----------|---------|
| Erisoojusmahtuvuse argument | 2p |

#### Ülesanne P5
*Kalamees märkab, et kala tundub olevat lähemal, kui ta tegelikult on. Selgita seda valguse murdumisega. Kuidas peaks kalamees arvestama?*

<details>
<summary>Lahendus</summary>

**Seletus:**

See on valguse murdumine (refraktsioon) vee ja õhu piiril.

- Valgus levib vees aeglasemalt kui õhus
- Kala küljest lähtuvad valguskiired muruvad vee-õhu piiril **normaalist eemale** (väiksemast murdumisnäitajast suuremasse — vesi → õhk)
- Inimsilm tajub valguse tulevat sirgjooneliselt → kala näib olevat kõrgemal (lähemal pinnale) kui tegelikult

$$n_1 \sin\theta_1 = n_2 \sin\theta_2 \quad (n_{vesi} \approx 1{,}33 > n_{õhk} = 1)$$

**Kalamehele:** Kala on sügavamal, kui näib. Viske nurka tuleb kohandada — visata tuleks sügavamale ehk rohkem alla veepinnast.

**Hindamisskeem:**

| Kriteerium | Punktid |
|-----------|---------|
| Murdumise mainimine vee-õhu piiril | 2p |
| Seletus, miks kala tundub lähemal | 2p |
| Praktiline järeldus kalamehele | 1p |

</details>
